# Contributing

Thanks for suggesting something. To keep the list useful:

- **Production relevance.** It should help run agents in production: evaluation, observability, safety,
  policy, cost or integration. General LLM libraries belong in other lists.
- **Open source.** The core must be open source. Hosted-only products aren't listed.
- **Alive.** Commits in the last six months and a usable README. Archived projects get removed.
- **One line.** `- [Name](link) - What it does, in plain words.` No marketing adjectives ("blazing",
  "revolutionary", "best-in-class").
- **Right section, alphabetical within it** where the section isn't ordered on purpose.
- **Disclose affiliation.** If you work on the project, say so in the PR.

One project per PR makes review quicker. The link checker runs on every PR, so check your links.
